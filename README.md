# Inspección de Extintores SDE — versión 5, fotos grandes

## Publicar en GitHub Pages
Subir los cinco archivos de esta carpeta a la **raíz** de `KyaraBenites/inspeccion-extintores` (reemplazar los anteriores). Se mantiene el mismo enlace GitHub Pages. Si se sigue viendo la versión anterior, recargar sin caché o cerrar y volver a abrir Safari.

## Exportaciones
- **PDF**: primero tabla A3 horizontal, luego anexos fotográficos. Por cada extintor se muestran **hasta dos fotos grandes por página**, sin reducirlas a miniaturas. Las fotos adicionales generan nuevas páginas.
- **Word DOCX**: tabla de controles editable y anexos fotográficos insertados a tamaño grande. El ajuste de páginas puede depender de la versión de Word.
- **Imágenes**: si hay una página descarga PNG; si hay varias, descarga ZIP de PNG individuales para evitar el límite de tamaño de imagen de algunos iPhone.
- **JSON**: respaldo íntegro.

## iPhone
Al pulsar «Preparar PDF», «Preparar Word» o «Preparar imágenes», aparece un panel con Visualizar / Descargar / Compartir. En Safari, para conservar un documento abierto en vista previa puede ser necesario usar **Compartir > Guardar en Archivos**.

## Privacidad e historial
Los archivos se generan en el navegador y se guardan localmente. GitHub Pages no sincroniza inspecciones entre dispositivos; exporta JSON regularmente para evitar pérdidas. Los documentos con muchas fotos pueden tardar y ser pesados.
